# Media Analytics Dashboard

A Flask-based dashboard for visualizing media analytics data from a unified SQLite database.

## Features
- Interactive charts using Plotly.
- Date range filtering.
- Detailed views for Programs and Categories.
- Social media engagement metrics.

## Installation

1. Clone the repository.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Access the dashboard at `http://127.0.0.1:5000`.

## Deployment
This application is ready for deployment on platforms like Heroku, Render, or a VPS. Ensure you have a database strategy (SQLite file or hosted PostgreSQL).
